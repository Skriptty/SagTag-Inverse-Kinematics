# Inverse Kinematics!

This mod adds Inverse Kinematics to lethal company, not to everything but the player legs
It isnt perfect since i cant figure out how to make it perfect but it tries its **best** to wrap arround cleanly

# KNOWN ISSUES

- one of the 2 foots sometimes twist into the ground, it is purely visual
- when standing on a rock, the foot sometimes isnt touching it and its kinda hovering over it
- sometimes the foot doesnt adapt to the ground, very rare scenario personally

# THINGS YOU SHOULD KNOW

This mod is completly clientside, which means that **NOBODY** in your lobby needs it and it will still work fine
If the mod cant detect the the ground, it will default to the idle animation of lethal company
If a mod **changes** any bones in the player model, the mod could fail and it will throw an error saying which bone is missing
Compatibility hasnt been tested a lot, any issues report them in the github

Thanks for reading and downloading!
